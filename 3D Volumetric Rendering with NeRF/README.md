# 3D Volumetric Rendering with NeRF
URL: [https://keras.io/examples/vision/nerf/](https://keras.io/examples/vision/nerf/)

## Setup
### Environment
Install dependencies to a virtual environment like venv.
``` 
python -m venv C:\venvs\nerf
C:\venvs\nerf\Scripts\activate
```

Install Packages:
```
python -m pip install --upgrade pip
python -m pip install tensorflow keras imageio tqdm matplotlib numpy
```
